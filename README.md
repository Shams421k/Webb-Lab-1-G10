# Viskaexpressen

Webbaserat bokningssystem för det fiktiva regionala tågbolaget Viskaexpressen. Användaren kan se tåglinjer och avgångar, välja datum, se lediga och upptagna sittplatser, boka en plats och senare söka upp bokningen med ett unikt bokningsnummer.

Kurs: 21WM1B Webb- och mobilutveckling, Högskolan i Borås  
Grupp: G10  
Gruppmedlemmar: Shams och Vincent

## Teknik

- C# och ASP.NET Core MVC (.NET 10)
- Entity Framework Core
- SQL Server Express LocalDB

## Köra projektet

Öppna `Viskaexpressen.sln` i Visual Studio, eller starta från den här mappen:

```powershell
dotnet run --project Viskaexpressen
```
